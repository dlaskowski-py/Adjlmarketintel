# Expo SDK 53

This project targets **Expo SDK 53** (React Native 0.79, React 19.0).
Read the versioned docs at https://docs.expo.dev/versions/v53.0.0/ before writing code.

- Run `npx expo install <pkg>` (not plain `npm install`) so versions stay SDK-compatible.
- `.npmrc` sets `legacy-peer-deps=true` to tolerate Expo's strict peer ranges.
- React Compiler is enabled (`experiments.reactCompiler`) via `babel-plugin-react-compiler`.
